名義貸しとは何が違うのですか？+
名義貸しは実態のない形式的な管理者登録であり、医療法違反に該当します。承継院長は実際にクリニックで診療を行い、管理者として実質的に医療機関を運営する正当なポジションです。契約書で責任範囲を明確にした上で就任します。
経営が悪化したら個人で責任を負いますか？+
当サイトで紹介する案件では、経営破綻リスクは法人側が負担し、院長個人の連帯保証を求めません。ただし、医療法上の管理者としての安全管理体制確保義務は院長に帰属します。詳細は契約書に明記し、弁護士チェックを推奨しています。
登録したら勤務先に知られませんか？+
知られません。登録情報は厳重に管理し、ご本人の許可なく第三者に開示することは一切ありません。案件紹介時も、先生の個人情報は匿名化した上で法人側に提示します。
将来の開業意向があっても応募できますか？+
応募可能です。むしろ、開業意向のある医師を高く評価する法人も多くあります。承継院長として経営ノウハウを学び、数年後に独立する——という計画を正直に伝えた上で採用されたケースも多数あります。
クリニックを将来的に買い取ることはできますか？+
案件によっては、一定期間（3〜5年）の勤務後にクリニックの買取オプション（優先交渉権）が契約に含まれるものもあります。将来の独立開業を視野に入れている医師にとっては、リスクを抑えたステップアップの手段となります。

2. 承継クリニック院長の報酬設計

M&A承継クリニックの院長報酬は、一般的な雇われ院長とは異なる構造を持つことが多くあります。

固定給＋インセンティブ型

多くの承継クリニックでは、基本年俸（固定給）に加えて、患者数や売上に連動するインセンティブを設けています。固定給で生活基盤を安定させつつ、クリニックの成長に応じて収入が増える設計です。

当サイトで紹介している案件の実績では、基本年俸1,500〜1,800万円＋インセンティブで、就任1年後の総年収は2,000〜2,500万円のレンジに収まるケースがほとんどです。

買取オプション付き契約の経済メリット

一部の案件では、3〜5年の勤務後にクリニックの買取オプション（優先交渉権）が契約に含まれています。この場合、院長として勤務しながら経営実績を積み、将来的にはオーナー院長として独立する道が開けます。

3. 年収交渉で確認すべき5つのポイント

  1. インセンティブの算定基準：売上連動か、患者数連動か、利益連動か。上限の有無も確認
  2. 社会保険の加入状況：厚生年金か国保か。年金は将来の収入に直結
  3. 退職金の有無：勤続年数に応じた退職金制度があるか
  4. 経費の扱い：学会参加費、書籍代、交通費が法人負担かどうか
  5. 買取オプションの条件：買取価格の算定方法、優先交渉権の期間

4. 失敗事例：年収だけで選んで後悔したケース

高額な年収に惹かれて飛びついたものの、入職後に「聞いていた話と違う」と感じるケースは少なくありません。

年収2,500万円という条件で承継院長に就任した40代内科医のケースでは、入職後にインセンティブの算定基準が実質的に達成不可能な水準だったことが判明。固定給は1,400万円で、前職の勤務医時代より低い結果に——。

年収の「上限」だけでなく、固定給の水準と、インセンティブの算定基準・達成実績を必ず確認しましょう。

リスク・法的責任

管理医師の法的責任と
名義貸しの違い

この記事でわかること
・管理医師（院長）が負う法的責任の具体的な内容
・名義貸しとの法的な違いと判断基準
・経営破綻時に院長が負うリスクの範囲
・契約書で確認すべき責任範囲のチェックリスト

1. 管理医師が負う法的責任とは

医療法では、すべての医療機関に「管理者」の設置を義務づけています。管理者には、安全管理体制の確保義務、従業者の監督義務、行政への届出義務が課せられます。

つまり、承継院長であっても「管理者」として就任する以上、保健所や厚生局に自分の氏名で届出がなされ、医療法上の責任を負うことになります。この点は、一般の勤務医とは明確に異なるポイントです。

2. 名義貸しとの決定的な違い

名義貸しとは、管理者として届出はされているものの、実際にはその医療機関で常勤していない、あるいは診療を行っていない状態を指します。これは医療法違反であり、行政処分の対象です。

承継院長は、実際にクリニックで診療を行い、管理者として実質的に医療機関を運営する正当な立場です。「名義だけ貸す」のとは根本的に異なります。

3. 経営破綻時のリスク

最も多くの医師が不安に感じるのが、クリニックの経営が悪化した場合の責任です。結論から言えば、経営破綻の財務的責任は法人の開設者が負います。院長個人が借入金の連帯保証人にならない限り、個人の財産が毀損されることは基本的にありません。

ただし、医療法上の管理者としての義務（安全管理体制、従業者監督）は院長に帰属するため、医療事故や法令違反が発生した場合は、管理者としての責任を問われる可能性はあります。

4. 契約書で確認すべきチェックリスト

  1. 連帯保証の有無：院長個人の連帯保証を求められていないか
  2. 経営判断の権限範囲：設備投資、人事権がどこまで院長にあるか
  3. 退職条件：管理者変更届の提出時期と手続き
  4. 競業避止義務：退職後の診療制限がないか
  5. 損害賠償の範囲：医療事故時の賠償責任の分担

1. パターン①：聞いていた話と全然違う

最も多い失敗パターンです。面接時に説明された患者数、スタッフ体制、設備投資計画が、入職後に大きく異なっていたケース。

40代内科医のケースでは、「1日50人の患者が来る」と聞いて入職したが、実際には20人程度。年収もインセンティブ込みの数字だったため、実質的には前職より低い収入になった。

防ぎ方：直近12ヶ月のレセプトデータ、月次の売上推移を必ず書面で確認する。口頭の説明だけで判断しない。

2. パターン②：オーナーとの方針対立

法人オーナーと医療方針が合わず、就任後に対立が深刻化するパターン。特に、営利目的の法人や異業種から参入した企業がオーナーの場合に発生しやすい。

防ぎ方：オーナーの経歴と経営方針を事前に確認。特に「実質的な経営判断は誰がしているか」を面接で直接聞く。

3. パターン③：将来の譲渡を約束されたのに反故

「3年後にクリニックを譲渡する」と口約束されていたものの、実際にはその約束が守られないケース。

防ぎ方：譲渡条件は必ず契約書に明記する。口約束は法的効力がないと考えるべき。

4. パターン④：自由診療クリニックの闇

美容・脱毛・AGAなどの自由診療クリニックで、実質的に「名義貸し」のような運用を強いられるケース。営利企業がオーナーの場合に特に注意。

防ぎ方：自由診療クリニックの場合は、診療方針の決定権が誰にあるかを必ず確認。「医師の判断で診療を拒否できるか」を基準にする。

5. パターン⑤：退職できない

管理者変更届の手続きが必要なため、後任が見つからない限り退職できないと言われるケース。

防ぎ方：退職予告期間と管理者変更の手続きを契約書で明記する。一般的には3〜6ヶ月前の予告で退職可能。

「そこが最も大きい。M&A後に最も怖いのは、院長交代による患者離れです。前院長から新院長への引き継ぎがスムーズに行われれば、患者の8〜9割は残ってくれる。逆に、引き継ぎなしで突然院長が変わると、3〜4割は他院に流れます。これは売上に直結する」

承継院長に求める人物像

——承継院長を採用する際、何を重視していますか？

「正直に言えば、経営手腕よりも人柄です。承継クリニックの患者さんは"前の先生に診てもらっていた"という信頼がベースにあります。新しい院長に求めるのは、その信頼を壊さない誠実さ、患者さんの話をちゃんと聞ける姿勢です。経営の数字は法人がサポートできますが、患者さんとの信頼関係は院長にしか作れない」

——開業意向がある医師はどう評価しますか？

「むしろ歓迎です。将来の開業を見据えている医師は、経営への意識が高い。"3〜5年後に独立したい"と正直に言ってくれる方のほうが、信頼できます。我々としても、その間に次の院長候補を育てればいい。Win-Winの関係です」

報酬設計の考え方

——買い手法人として、承継院長の報酬はどう設計していますか？

「固定給で安定した生活基盤を保証した上で、クリニックの成長に応じたインセンティブを設けています。基本年俸は1,500〜1,800万円で、インセンティブ込みで2,000〜2,500万円が目安。重要なのは、インセンティブの算定基準を透明にすること。ここを曖昧にすると信頼関係が壊れる」

——買取オプションについてはどうですか？

「ケースバイケースですが、我々は積極的に提案しています。院長にオーナーシップを持ってもらうことで、クリニックへのコミットメントが格段に上がる。買取価格は就任時の評価額をベースに、業績に応じた調整を加える形が多い」

承継院長を検討している医師へのメッセージ

「"雇われ院長"という言葉のネガティブなイメージに引っ張られすぎないでほしい。承継院長は、患者・スタッフ・買い手法人の三者にとって不可欠な存在です。あなたが座ることで、一つのクリニックが存続し、地域の医療が守られる。それはとても意義のある仕事だと思います」

プロフィール

S
S氏（40代）
医療法人○○会 理事長。東北地方で内科・小児科を中心に3院を運営。いずれもM&Aによる承継で取得。地域医療の継続を経営理念に掲げる。

地方の承継M&Aが抱える課題

——地方でのクリニックM&Aは、都市部と何が違いますか？

「院長候補を見つけるハードルが圧倒的に高い。都市部なら転職サイトに出せば応募がありますが、地方はそうはいかない。しかも地方のクリニックほど、前院長が地域に根ざした信頼を築いている。だからこそ"この人なら任せられる"という院長を見つけることが、承継の成否を分ける」

院長面接で見ているポイント

——面接では何を見ていますか？

「3つあります。1つ目は患者への姿勢。面接で"売上"や"効率化"の話ばかりする医師は合わない。地方の患者さんは"先生に話を聞いてもらえた"ということ自体に価値を感じている。2つ目はスタッフへの敬意。承継クリニックのスタッフは前院長のやり方に慣れているので、いきなり変えようとする人は失敗する。3つ目は長期的な視点。短期間で辞められるのが一番困る」

うまくいった承継・失敗した承継

——成功と失敗、それぞれの共通点は？

「うまくいったケースは、例外なく引き継ぎ期間を十分に取っている。前院長が2〜3ヶ月並走して、患者さんに"新しい先生です"と紹介する。この地味なプロセスが全てです。逆に失敗したケースは、引き継ぎなしでいきなり院長交代したもの。患者数が半年で4割減った」

——前院長との関係構築のコツは？

「前院長をリスペクトすること。引退するとはいえ、何十年もそのクリニックを支えてきた人です。"先生のクリニックを引き継ぐ"という敬意を態度で示せる院長は、前院長からもスタッフからも患者からも受け入れられる」

地方ならではの報酬・働き方

——地方クリニックの承継院長の報酬水準はどうですか？

「都市部と遜色ない、むしろ高めのケースが多い。地方は医師不足なので、報酬で魅力を出さなければ人が来ない。基本年俸1,800〜2,200万円程度で、住宅手当や引越し費用の負担も一般的です。加えて、通勤時間が短い、当直がない、週4.5日勤務——QOLは確実に上がります」

承継院長を検討している医師へ

「地方のクリニックを引き継ぐということは、その地域の医療を守るということ。大げさに聞こえるかもしれませんが、地方ではクリニックが閉じると、次に一番近い医療機関が車で30分先になる。あなたが院長として座ることで、何千人という患者さんの医療アクセスが守られる。やりがいという意味では、これ以上のポジションはないと思います」
